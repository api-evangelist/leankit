# LeanKit (Planview AgilePlace)

> LeanKit is the enterprise Kanban platform now shipped by Planview as Planview AgilePlace. Teams visually track and manage the flow of work from strategy to delivery across boards, lanes, cards, taskboards, and connected parent/child hierarchies. LeanKit exposes a documented RESTful v2 API at `https://{account}.leankit.com/io/`, a SCIM 1.1 User Provisioning API, and an Advanced Reporting export API.

Key facts an agent should know before calling this API:

- Base URL is per-account: `https://{account}.leankit.com/io/`. There is no single shared host. The `leankit.com` apex and `www` hosts no longer present a matching TLS certificate; only per-account and `login` subdomains work.
- Authentication is HTTP Basic (base64 email:password) or Bearer with a long-lived opaque API token. Tokens are created with `POST /io/auth/token` or from the "My API Tokens" tab in the user profile, are displayed only once, and never expire. There is no OAuth 2.0 and there are no scopes.
- Rate limits are points per rolling 60-second window, per authenticated user, shared across all of that user's tokens. Read `X-RateLimit-Limit`, `X-RateLimit-Remaining`, and `X-RateLimit-Reset` on every response; on `429` honour `Retry-After`.
- List endpoints page with `limit` and `offset` and return a `pageMeta` envelope (`totalRecords`, `offset`, `limit`, `startRow`, `endRow`).
- Use the `since` parameter on `GET /io/card` for incremental sync instead of polling full card state.
- **There is no idempotency key.** Retried writes create duplicates. Correlate with `externalCardId`.
- Errors are HTTP status codes only — no `application/problem+json`, no error-code registry. `422` means required information was missing or invalid.
- Dates are ISO 8601 in UTC. `X-HTTP-Method-Override` lets a POST stand in for PUT, PATCH, or DELETE.
- The legacy `/kanban/api` v1 surface is marked for deprecation; do not build on it.
